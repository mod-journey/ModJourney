# Contributing

## Translate questbook

- open the questbook
- go to "Player Preferences" via the button, bottom right of the GUI

  ![screenshot][preferences]
- Scroll down and set `Local Overwrite` to the language you like to edit (e.g. `de_de` or `en_us`)

  ![screenshot local overwrite][local-overwrite]
